## Makine / ortam gerçekleri

- Windows 11, RTX 5090 32 GB (sm_120), sistem Python 3.10 + **torch 2.11.0+cu128 +
  transformers 4.46.3** — bunlara asla dokunulmaz. Her modalite `~/LocalAIStudio/envs/<ad>`
  altında `--system-site-packages` venv; eksik paketler yalnız venv'e kurulur.
- **Tuzak:** `uv pip install` venv'e CPU-only torch (2.14) çekebiliyor (imagex kurulumunda
  oldu) → `uv pip uninstall torch torchvision` ile sökülür, sistem torch geri görünür.
- Env'ler: `image` (SDXL/LTX/Wan/imgtool/videotool — diffusers 0.33.1, torchao **0.10.0**),
  `imagex` (yeni nesil görsel — diffusers 0.38.0 + transformers 4.57.1 + hub 0.36.2),
  `audio` (faster-whisper, kokoro, coqui-tts, transformers 4.57.6), `llm`, `3d`.
- Disk: C: 1.3 TB; oturum başında %97 doluydu (46 GB boş), kullanıcı yer açtı (~230 GB boş).
- API dev modu token'sız yalnız loopback; LAN'a `--host 0.0.0.0` ile çıkarken token
  zorunlu (otomatik üretilir). Aktif indirme hızı ~10 MB/s (2 paralel dosya).
- `python`/PowerShell konsolunda Türkçe karakterler bozuk görünür (dosyalar etkilenmez);
  Python çıktılarında `PYTHONIOENCODING=utf-8` kullan. PowerShell 5.1 BOM'suz UTF-8 .ps1
  dosyalarını ANSI okur → .ps1 dosyaları ASCII yazıldı.
