# ADR-0014: GPU Destek Matrisi

**Durum:** accepted · 2026-07-18

**Karar:** CUDA (birincil) · ROCm (Linux birincil) · MPS (macOS) · CPU fallback · DirectML
(Windows AMD/Intel, opsiyonel).

**Gerekçe:** Windows+ROCm resmi olarak zayıf; **dürüst bir destek matrisi** yayınlanır —
desteklenmeyen kombinasyonlar gizlenmez, açıkça belirtilir.
